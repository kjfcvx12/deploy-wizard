# 2026-11-16

## Local MCP server, stage 1 (branch `feat/mcp-local`)
Spec `docs/superpowers/specs/2026-11-16-mcp-design.md`, plan tasks 1-7. REST API and `docs/api-spec.md` unchanged; `CLAUDE.md` unchanged.

Built:
- T1 `Wizard_Client` (httpx REST client, Korean `Wizard_Error`, log tail).
- T2 `guard.py`: allow-list summaries, `guard_text_clip` (mask + clip), untrusted-data wrapper, `Confirm_Store` (5 min, one use, bound to tool + args).
- T3 read tools logic in `Mcp_Service` (analyze, list, get, wait up to 120 s, logs, issues, health, connections).
- T4 action tools logic: preview -> token -> execute for deploy / redeploy / stop / start / delete; live-deploy limit check in the service (one place).
- T5 `server.py`: 13 tools registered with annotations; `__main__.py` stdio entry; settings `WIZARD_API_URL`, `WIZARD_API_TOKEN`, `MCP_MAX_LIVE_DEPLOYS`, `MCP_CONFIRM_TTL_SECONDS`.
- T6 elicitation flow: action tool without token asks the user directly when the client supports it; unsupported -> token preview; declined/cancelled -> `{"status":"cancelled","message":...}`.
- T7 fix wave (tool descriptions + instructions state both confirmation paths; decline message tells the model not to re-ask; `Confirm_Schema` field has Korean title/description; `check_health.detail` masked + clipped) and docs (README section, architecture, features, milestones, HISTORY, spec status).

SDK note: `mcp` 2.x (pinned 2.3.0) differs from v1 - server class is `mcp.server.mcpserver.MCPServer` (not `FastMCP`), types from `mcp_types`, in-memory `Client(srv, mode="legacy")` for tests.

Decisions:
- Elicitation is additive: the token path stays, so clients without elicitation still work and a given token skips the dialog.
- Live-deploy limit 3 (`MCP_MAX_LIVE_DEPLOYS`), counted from `/api/deploys` statuses (incl. `deleting`).
- No secrets through chat: env-var values are entered in the web UI; MCP has no tool for them.
- Logs / error text / explanations are masked, clipped and wrapped as untrusted data.
- Docs warn never to put the five action tools on an auto-allow list.
- Run the process from the project root (module path and `.env` are cwd-relative); Desktop JSON uses `env.PYTHONPATH`.
